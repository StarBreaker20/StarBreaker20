## Selected work

### [rendrr — deterministic video editing and rendering](https://github.com/StarBreaker20/Renderer)

[![rendrr video catalog](https://raw.githubusercontent.com/StarBreaker20/Renderer/claude/video-catalog-frame-edit-mt8fhu/docs/rendrr-catalog.jpg)](https://github.com/StarBreaker20/Renderer)

A Next.js and Remotion video editor where the browser preview, paused-frame
filmstrip, and Lambda export share one composition. Overlays are stored in
composition coordinates so preview and final render stay frame-accurate.

`TypeScript` · `Next.js` · `Remotion` · `Zustand` · `AWS Lambda`

### [SG-GNN — spike-gated graph neural network research](https://github.com/StarBreaker20/SG-GNN)

A ten-stage research implementation combining message-passing graph networks
with leaky integrate-and-fire neurons for binary edge-existence decisions. The
repository documents the QM9 and ZINC experiments, ablations, limitations, and
reproduction path.

`Python` · `PyTorch` · `PyTorch Geometric` · `SpikingJelly` · `GNNs`
